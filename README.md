# Customer_Behavior_Analysis_Project
Customer Shopping Behavior Analysis using Python, MySQL, and Power BI. Analyzed customer demographics, purchasing patterns, product categories, spending, discounts, subscriptions, payment methods, and purchase frequency to uncover actionable business insights through data analysis and interactive dashboards.

## Overview
This end-to-end data analytics project explores customer shopping patterns, purchasing habits, and subscription trends. The goal of this analysis is to transform raw retail data into actionable business insights through exploratory data analysis (EDA), database management, and interactive data visualization.

## Dataset
- **Source:** Retail Customer Shopping Behavior Dataset
- **Size:** ~3,900 customer records
- **Key Features:** Customer ID, Age, Gender, Item Purchased, Category, Purchase Amount (USD), Location, Size, Color, Season, Review Rating, Subscription Status, Shipping Type, and Frequency of Purchases.

## Tools & Technologies
- **Python (Pandas, NumPy, Matplotlib, Seaborn):** Used for data loading, exploratory data analysis (EDA), and data cleaning.
- **MySQL:** Used for relational database storage, data querying, and aggregating key metrics.
- **Power BI:** Used for building an interactive executive dashboard.
- **Markdown / Word:** Used for creating the final project documentation and summary report.
## Project Steps
1. **Data Loading & Exploration (Python)**: Imported the raw dataset into a Pandas DataFrame, inspected data types, checked for missing values, and calculated summary statistics.
2. **Data Cleaning:** Handled missing values, standardized categorical text formats, and prepared clean data for database migration.
3. **Database Management & SQL Queries (MySQL)**: Created a relational database schema, loaded the cleaned dataset into MySQL, and executed complex SQL queries to extract insights on sales trends and customer demographics.
4. **Dashboard Development (Power BI)**: Connected Power BI to the data source, established data relationships, built calculated measures (DAX), and designed a multi-chart interactive dashboard.
5. **Reporting & Insights:** Synthesized the findings into a clear business report outlining actionable recommendations for marketing and customer retention strategies.

## Recommendations

Based on the customer behavior and sales analysis from the dashboard, here are key, actionable recommendations to improve revenue and customer retention:

* **Target High-Value Subscriptions:** Since non-subscribed customers make up the majority (73%), launch targeted email campaigns or exclusive discounts for frequent buyers to convert them into subscribers.
* **Capitalize on Top Categories:** Clothing and Accessories drive the highest revenue. Increase inventory levels and feature promotional bundles for these categories during peak seasons.
* **Optimize Marketing by Age Group:** Young Adults and Middle-aged customers show strong purchasing activity. Tailor digital marketing and social media ads specifically to appeal to these demographics.
* **Boost Winter and Fall Sales:** Leverage seasonal trend insights to run special marketing pushes and holiday promotions during lower-performing seasons.
